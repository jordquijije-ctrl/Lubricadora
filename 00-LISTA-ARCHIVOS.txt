MAPA CONCEPTUAL DE FLUJO
========================

USUARIO                 FRONTEND (Browser)         BACKEND (Node.js)      BD (SQL)
───────────────────────────────────────────────────────────────────────────────
                                                 
  [Login]─────────→  js-auth.js ───────────→ server.js
                      POST /auth               routes → controller
                                               
  [Ver Productos]──→ js-productos.js ──────→ GET /api/productos
                      fetch()                  ProductoController.getAll()
                                               ProductoModel.getAll()
                                                            └──→ SELECT * FROM Productos
                      [Tabla HTML]←──────────────JSON Response←─┘
                      
  [Crear Producto]─→ MODAL.open()
                      [Formulario]
                      PRODUCTOS.save()──────→ POST /api/productos
                                               ProductoController.create()
                                               ProductoModel.create()
                                                            └──→ INSERT INTO Productos
                      TOAST.show("✅")←──────────JSON Response←─┘
                      PRODUCTOS.loadProductos()  [Tabla actualizada]
                      
  [Editar]──────────→ PRODUCTOS.editModal()
                      [Formulario lleno]
                      PRODUCTOS.save()──────→ PUT /api/productos/:id
                                               [Similar a crear]
                      
  [Eliminar]────────→ confirm("¿Seguro?")
                      PRODUCTOS.delete(id)─→ DELETE /api/productos/:id
                                               [Eliminar de BD]

CÓMO ENCONTRAR CÓDIGO
====================

¿Dónde está... ?

El login                    → index.html + js-auth.js + css-login.css

La navegación              → js-nav.js
La conexión a BD           → db.js
Las queries SQL            → models-Producto.js
Los endpoints API          → routes-productos.js + controller-Producto.js
Los colores (temas)        → css-base.css (:root)
