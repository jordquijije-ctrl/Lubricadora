🎯 SOBRE EL MÓDULO DE FACTURAS:

¿QUÉ NECESITAS HACER PARA QUE FUNCIONE?

1. ✅ YA ESTÁ ARREGLADO - No hay errores de conexión
2. ✅ YA EXISTE - Tabla Facturas en la BD
3. ✅ YA EXISTE - Tabla Factura_Detalles en la BD
4. ✅ YA FUNCIONA - Actualización automática de stock

SI AÚN NO VES LAS FACTURAS:

Verificar:
  □ SQL Server esté corriendo
  □ Las tablas Facturas y Factura_Detalles existan
  □ Reiniciar el servidor (npm start)
  □ Abrir Developer Tools (F12) para ver errores

CREAR FACTURA:

  1. Ve a Facturación → + Nueva Factura
  2. Ingresa nombre del cliente
  3. Selecciona productos del inventario
  4. Ajusta cantidades
  5. Click en "Guardar Factura"
  
  AUTOMÁTICAMENTE:
  ✓ Se genera número FAC-XXXX
  ✓ Se reduce stock de productos
  ✓ Se registra movimiento de salida
  ✓ Se guarda en estado "Pendiente" o "Pagada"
