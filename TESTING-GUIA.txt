TESTEAR FACTURACIÓN
───────────────────

1. Sidebar → Facturación
   Ves tabla con 4 facturas de ejemplo (FAC-4821, FAC-4820, etc)

2. Clic "+ Nueva Factura" (botón amarillo arriba)
   Se abre modal con:
   - Número auto (ej: FAC-4822)
   - Campo cliente
   - Selector de productos (con stock disponible)
   - Tabla de detalles (cantidad, precio, subtotal)
   - Total calculado automático
   - Campo estado (Pagada/Pendiente)

3. Agregar productos:
   - Haz clic en un producto (ej: Castrol GTX)
   - Se marca checkbox
   - Aparece en tabla de detalles
   - Cambia cantidad si quieres
   - Total se recalcula

4. Guardar factura
   → Stock se actualiza automáticamente
   → Movimiento de salida se registra
   → Toast: "✅ Factura creada exitosamente"
   → Tabla se actualiza con nueva factura

5. Acciones en tabla:
   - 👁️ Ver detalle
   - ✏️ Cambiar estado
   - ❌ Anular (revierte stock)

ENDPOINTS PARA TESTEAR CON POSTMAN/CURL
────────────────────────────────────────

GET todas las facturas:
  curl http://localhost:3000/api/facturas

GET todos los movimientos:
  curl http://localhost:3000/api/movimientos

GET todos los proveedores:
  curl http://localhost:3000/api/proveedores

Crear nueva entrada:
  curl -X POST http://localhost:3000/api/movimientos/entrada \
    -H "Content-Type: application/json" \
    -d '{"producto_id":1,"cantidad":10,"usuario":"admin"}'

Crear factura:
  curl -X POST http://localhost:3000/api/facturas \
    -H "Content-Type: application/json" \
    -d '{
      "cliente":"Carlos",
      "total":100,
      "usuario":"admin",
      "detalles":[
        {"producto_id":1,"cantidad":2,"precio_unitario":14.99,"subtotal":29.98}
      ]
    }'
