FLUJOS LÓGICOS
══════════════

CREAR FACTURA:
1. Usuario selecciona productos → cantidad
2. Sistema calcula subtotales y total
3. Número se genera automático (FAC-4822, etc)
4. Al guardar:
   a. INSERT en tabla Facturas
   b. INSERT detalles en Factura_Detalles
   c. UPDATE Productos (stock -= cantidad) para cada producto
   d. INSERT movimientos tipo 'salida' automáticos
5. Todo en transacción (si falla, se revierte todo)

REGISTRAR ENTRADA:
1. Usuario selecciona producto
2. Ingresa cantidad a agregar
3. Selecciona proveedor (opcional)
4. Ingresa referencia (Orden #XXX)
5. Al guardar:
   a. INSERT en tabla Movimientos
   b. UPDATE Productos (stock += cantidad)
6. Instantáneo y automático

ANULAR FACTURA:
1. Usuario da clic en anular
2. Sistema:
   a. SELECT Factura_Detalles (qué se vendió)
   b. Para cada detalle: UPDATE Productos (stock += cantidad) REVERTIR
   c. UPDATE Facturas estado = 'Anulada'
3. Todo reversible y rastreable
