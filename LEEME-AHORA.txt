📋 MÓDULO DE FACTURAS - GUÍA RÁPIDA:

¿CÓMO CREAR UNA FACTURA?

1. Ve a "Facturación" en el menú
2. Click en "+ Nueva Factura"
3. Llena los datos:
   • Nombre del cliente
   • RUC (opcional)
4. Selecciona productos del inventario
5. Ajusta cantidades
6. El total se calcula automáticamente
7. Click en "Guardar Factura"

AUTOMÁTICAMENTE:
  ✓ Se genera un número FAC-4801, FAC-4802, etc.
  ✓ Se reduce el stock de los productos
  ✓ Se registra un movimiento de salida
  ✓ Se guarda la factura como "Pendiente" o "Pagada"

═══════════════════════════════════════════════════════════════════════════════════

⚠️ SI ALGO NO FUNCIONA:

PROBLEMA: Aún veo error en la consola del navegador (F12)
SOLUCIÓN: 
  1. Verifica que SQL Server esté corriendo
  2. Verifica que las tablas existan en la BD
  3. Revisa el archivo .env y que las credenciales sean correctas
  4. Reinicia el servidor (Ctrl+C y npm start)

PROBLEMA: No puedo crear facturas
SOLUCIÓN:
  1. Verifica que haya productos en Productos
  2. Crea al menos una entrada de inventario
  3. Luego intenta crear la factura

PROBLEMA: El stock no se actualiza
SOLUCIÓN:
  1. Presiona F5 para refrescar la página
  2. Verifica en la tabla de Productos
  3. Si no se actualizó, consulta la BD directamente
