Se han implementado 3 módulos nuevos principales con soporte para iconos SVG y base de datos SQL:

════════════════════════════════════════════════════════════════════════════════

1. MÓDULO DE FACTURACIÓN 📄
───────────────────────────

✓ Crear nuevas facturas
✓ Registrar detalles de productos vendidos
✓ Automático: genera número de factura secuencial (FAC-4821, FAC-4822, etc)
✓ Cambiar estado (Pagada, Pendiente, Anulada)
✓ Anular factura (revierte automáticamente stock de productos)
✓ Ver historial de facturas recientes
✓ Tabla con información completa (cliente, productos, total, hora, estado)

ARCHIVOS CREADOS:
  - models-Factura.js (Queries SQL, lógica de BD)
  - controller-Factura.js (Validaciones, errores)
  - routes-facturas.js (6 endpoints REST)
  - js-facturas.js (Interfaz frontend, CRUD)

ENDPOINTS API:
  GET    /api/facturas           → Obtener todas las facturas
  GET    /api/facturas/:id       → Obtener factura con detalles
  GET    /api/facturas/proximo   → Obtener próximo número
  POST   /api/facturas           → Crear nueva factura
  PUT    /api/facturas/:id/estado → Cambiar estado
  PUT    /api/facturas/:id/anular → Anular factura (revierte stock)

FLUJO DE DATOS COMPLETO
───────────────────────

1. REGISTRAR ENTRADA:
   Usuario → js-movimientos.js → POST /api/movimientos/entrada 
   → controller → modelo → INSERT Movimientos → UPDATE Productos (stock +)

2. CREAR FACTURA:
   Usuario → js-facturas.js → POST /api/facturas 
   → controller → modelo → INSERT Facturas + INSERT Factura_Detalles 
   → UPDATE Productos (stock -) → INSERT Movimientos (movimiento automático)

3. ANULAR FACTURA:
   Usuario → js-facturas.js → PUT /api/facturas/:id/anular 
   → controller → modelo → SELECT Factura_Detalles 
   → UPDATE Productos (stock +) para cada producto → UPDATE Facturas estado='Anulada'

CÓMO USAR
─────────

1. Ejecutar setup-database.sql en SQL Server (crea nuevas tablas y datos)
2. Reiniciar servidor: npm start
3. Abrir en navegador: http://localhost:3000
4. Login con: admin / admin123
5. Navegar a: Facturación → crear una factura
6. Navegar a: Movimientos → registrar entrada/salida
7. Navegar a: Proveedores → crear nuevo proveedor
